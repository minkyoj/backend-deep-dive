# Backend Deep Dive

이 저장소는 백엔드 개발자로서 **기술 역량 강화**를 위해 만든 개인 학습/정리 리포지토리입니다.  
실제 현업에서 마주한 문제를 기반으로 **핵심 CS 개념 + 백엔드 실무 개념**을 정리하고 있으며,  
면접에서 자주 등장하는 주제 위주로 체계적으로 기록하고 있습니다.

---

## 이 저장소의 목적

- DB 성능 최적화 (인덱스, 실행계획, 트랜잭션) 정리  
- Redis / 캐시 / 메시지큐 등 백엔드 핵심 컴포넌트 심화  
- Docker & 배포 실습을 통해 서비스 운영 경험 쌓기  
- 실무 예제 + 코드 + 설명으로 나만의 기술 아카이브 구축
